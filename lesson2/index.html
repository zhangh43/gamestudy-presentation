认识概念 · 01

以 0 为界，认识正数和负数

小于 0 的数
−3

负数

在正数前加上“−”号。
例如：−1、−3、−0.5。

“−3”读作“负三”。

正数与负数的分界
0

零

0 既不是正数，
也不是负数。

它可以表示我们约定的基准。

大于 0 的数
+3

正数

可以带“+”号，也可以省略。
例如：+1、3、0.5。

“+3”和“3”表示同一个数。

一起读：−3，0，+3。数值前的正负号，能帮助我们区分相反的意义。
生活里的数学 · 02

同样的数字，可以表示相反的意义

🌡️

温度：零上与零下

+3℃−3℃

零上 3℃，或零下 3℃。

以 0℃ 为基准；0℃ 也有温度。

🌊

位置：海面上与海面下

+20−20

海面上方 20 米，
或海面下方 20 米。

约定海平面为 0 米，上方为正。

🎮

得分变化：增加与减少

+5−5

增加 5 分，或减少 5 分。

约定增加为正、减少为负。

把数字画出来 · 03

在数轴上，找到正负数的位置

← 0 的左边：负数原点 0正数：0 的右边 →

越往右，数越大

−3 < −1 < 0 < +2。
−1 比 −3 大，因为它更靠右。

加一个数，就移动一次

加正数 → 向右走；加负数 → 向左走。
例如：2 + (−4)，从 2 向左走 4 格。

记住：起点、方向、步数。接下来，用这三个线索完成补给任务。
