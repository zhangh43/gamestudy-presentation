# AI 在学科的趣味应用｜第一课

直接双击 `index.html` 即可演示；点击课件中的“打开游戏”会打开 `game.html`。

建议使用浏览器全屏。快捷键：左右方向键翻页，空格下一页，`F` 全屏，`N` 显示教师备注，`R` 清除本设备的投票记录。

## 投票说明

每轮在每个浏览器中只能投一次，记录保存在 `localStorage`。这是无服务器课件，因此不会跨设备汇总票数。全班共用投影时，可举手表决后由老师点击多数选项。
