第 2 步 · 提示词

把“想要”说得具体

请用 HTML + CSS + JavaScript 制作一个打地鼠游戏。
主题：______；目标玩家：初中生。
玩法：点击______得 1 分，点击______扣 1 分。
一局时长：______秒；难度变化：______。
必须包含：开始/重玩、计分、倒计时、点击反馈。
视觉风格：______；特别创意：______。
请输出一个可直接打开运行的单文件 HTML。

AI 创造师先提交完整提示词；其他成员检查有没有遗漏和矛盾。
